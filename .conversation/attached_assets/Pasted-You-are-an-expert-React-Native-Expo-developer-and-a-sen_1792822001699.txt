═══════════════════════════════
1. PURPOSE OF THE APP
═══════════════════════════════
A photo studio takes camera equipment to outside events (weddings, functions). Equipment often gets forgotten or lost. This app solves that with a two-stage checklist:

STAGE 1 – GEAR INVENTORY
The user adds ALL their studio gear to the app once (camera bodies, lenses, flashes, batteries, memory cards, tripods, gimbals, lights, cables, bags, etc.), grouped by category.

STAGE 2 – EVENT PACKING FLOW
For every function/event:
  a) CREATE EVENT: name, date, venue, notes.
  b) SELECT GEAR: user picks which gear items are going to this event from the inventory (checkbox multi-select, with search + category filter + "select all in category").
  c) PACK CHECKLIST (leaving the studio): the selected items appear as a checklist. User ticks each item as it is packed into the bag. Show a progress bar (e.g. 12/20 packed). When all are ticked, show a "Ready to go" success animation.
  d) RETURN CHECKLIST (after the event): when the user is back, the same items appear again. User ticks each item as it is returned. 
  e) FINAL STATUS MESSAGE:
     - If everything is ticked → show a beautiful success screen: "All gear returned safely ✅".
     - If anything is NOT ticked → show a warning screen: "⚠ Missing items" with the list of missing items (name + category) so the user knows exactly what was lost or left behind.
  f) Save event history (completed events with status: Complete / Items Missing).
